# Tee-Time — skærmbilleder uden ramme/præsentation

Rene PNG's af selve app-skærmene — uden device-bezel (iPhone/iPad-ramme) og uden top-menuen (Gæst/Personale/Menuadmin), som kun er en del af prototype-præsentationen, ikke selve designet.

01-hjem, 02-menu, 03-produkt, 04-kurv, 05-checkout, 06-bekraeftelse, 07-status, 08-tidligere, 09-tidligere-detalje, 10-tilbud

## tablet-app/ (iPad-format, liggende, eksporteret i 2×)
01-personale, 02-menuadmin

Kildekoden til begge formater ligger i `Tee-time.dc.html` (se `design_handoff_tee_time_app/README.md` for fuld spec: farver, typografi, state, interaktioner).
